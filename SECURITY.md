# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues. Use GitHub's private reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**. You will get an answer as soon as possible.

Relevant areas include the global keyboard hook, simulated keyboard input, the clipboard backup and restore, the model download and its integrity check, and the local data stored under `%LOCALAPPDATA%\LocalDictation`.

## Supported versions

Only the latest state of the default branch and the latest release receive fixes.
