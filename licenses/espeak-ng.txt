Text-to-speech components contained in sherpa-onnx-c-api.dll

The prebuilt sherpa-onnx-c-api.dll from the NuGet package org.k2fsa.sherpa.onnx.runtime.win-x64 1.13.5
statically contains espeak-ng and piper-phonemize, because sherpa-onnx is built with text-to-speech
support by default (SHERPA_ONNX_ENABLE_TTS=ON). Local Dictation only uses the offline speech
recognition API and never calls these functions.
